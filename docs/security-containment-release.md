## Intentional availability changes

Node returns 503 for all requests beneath `/api/cases`, `/api/clients`, `/api/inquiries`, `/api/team`, `/api/reports`, `/api/payments`, `/api/csv-manager` and `/api/deepgram`. The key router itself also denies every method. This covers direct Node access, not merely frontend UI. There is no environment switch or compatibility exception to reopen these routes.

Python refuses `/api/analyze-document`, `/api/chat-with-pdf`, `/api/generate-legal-draft` and `/api/generate-legal-draft-stream`, including JSON-only generation on those paths because they share document-capable handlers. Trailing-slash paths are also refused. Other paths retain their existing behavior. Existing document data is retained untouched.

Deepgram English/Hindi options now display an explicit maintenance message and do not request microphone access. Native browser speech remains available for the existing browser-language options; no unreviewed provider fallback is added. The H2 adapter/queue/caret algorithms remain present and tested. H3, legacy-font autosave, personal drafts, bookmarks, Node OCR/searchable PDF, judgement sanitization and exports are retained. H5 CSV internals are still regression-tested but the public CSV API is intentionally suspended.

Operators must explicitly accept and communicate these feature interruptions before deploying containment. An all-eight, fully enabled release cannot be claimed while these boundaries are necessary. Old admin clients without bearer headers get 401; update frontend and reauthenticate rather than weakening server authorization.
